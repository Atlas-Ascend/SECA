## 1. Executive finding

The organism already has a defined body map and substantial pieces of its nervous and cardiovascular architecture. The canonical design is not missing a new bus or a new router:

- **Nervous system / signal circulation:** Ghost Atlas Estate Event Gateway, using typed organism-event envelopes, immutable correlation lineage and explicit state classes.

- **Cardiovascular system / capability and I/O circulation:** CrownGrid + HYPERNET, routing by capability, authority, locality, capacity, policy and node health. BodyForge (or its canonical successor) regulates resource envelopes and backpressure.
- **Executive control:** JANUS PRIME / ODIN authorizes; cognition proposes but does not self-authorize.
- **Motor execution:** EDEN/Cali and bounded executors perform authorized work; MetaForge builds and repairs.
- **Immune boundary:** Medusa enforces permission, privacy, quarantine and egress policy.
- **Truth court:** SECA / DevOS independently verifies criteria and release state.
- **Evidence fabric:** ProofGrid retains evidence and receipts; it does not strengthen weak evidence into stronger claims.
- **Memory and temporal return:** Thoth retains provenance; Universal Atlas represents topology; SESHAT retains temporal truth.
- **Interoception / homeostasis:** AURA and Runtime Observatory observe health, coherence, freshness, drift and failure.
- **Repair / restoration:** PROMETHEUS proposes improvements; JANUS authorizes; MetaForge implements; Hydra/Reverse Uno reconciles; OSIRIS restores; SECA re-verifies.

The architecture therefore exists as a canonical map and multiple repository-level contracts. **The full organism is not yet proven as one live, end-to-end nervous/circulatory system.** Repository presence, route declarations and unit-test source are not proof of deployed connectivity.

## 4. Nervous-system contract

The Event Gateway remains the single event-circulation owner. Do not create a second message bus, correlation service or competing event ledger.

Canonical circulation law:

`INTENT DOWN → EVENTS ACROSS → EVIDENCE UP → MEMORY BACK → IMPROVEMENT AROUND`

Every material event must preserve immutable `correlationId` and `missionId`; append `caseId`, `packetId`, `roleId`, `agentInstanceId`, `leaseId`, `capabilityId`, `modelId`, `nodeId`, `authorizationId`, `executionId`, `verdictId` and `receiptId` when issued. Never regenerate lineage at a subsystem boundary.

Required typed signal classes remain distinct:

- `COMMAND`: authorized requested action.
- `PACKET`: durable bounded work.
- `EVENT`: happened fact.
- `OBSERVATION`: sensed state.
- `STATE_DELTA`: canonical temporal change.
- `HEALTH`: liveness, readiness and coherence.
- `PROOF`: evidence for a claim.
- `ALERT`: condition requiring routing.
- `LEASE`: temporary capability and assignment.
- `RECOVERY`: authorized repair or restoration.
- `RETURN`: verified outcome integrated into the originating context.

Existing event schema state classes are `OBSERVED`, `INFERRED`, `DECISION`, `ACTION`, `PROOF`, `MEMORY` and `IMPROVEMENT`. These are epistemic/lifecycle classifications, not replacements for the signal types above. Observed and inferred data must never be merged into one truth field.

## 5. Cardiovascular / I/O circulation contract

CrownGrid + HYPERNET are the capability-addressed circulation and routing fabric. They do not own mission truth, packet lifecycle, executive authorization or proof.

Every execution route must carry:

- JANUS authorization decision and explicit scopes;
- capability identifier and policy;
- data/context classification and egress constraints;
- locality requirement (`device`, `local`, `edge`, `cloud` or `any`);
- preferred and denied node IDs;
- current node health, freshness and capacity;
- deadline, idempotency key and bounded retry count;
- required proof class, SECA requirement and Thoth persistence requirement.

Route selection must exclude unhealthy, denied, incapable or saturated nodes. No eligible route produces an explicit blocked/no-route outcome; it must never silently fall back across a privacy or locality boundary. Provider substitution must preserve mission, packet and correlation identity.

BodyForge or its already-canonical successor owns resource regulation: CPU/GPU/RAM, disk, power/thermal limits, concurrency, model residency, execution duration, priority and queue backpressure. Resource pressure may defer or reject execution; it may not silently drop a packet or alter mission intent.


The repair loop must be idempotent, bounded, auditable and stoppable. Failed evidence is retained after recovery.

The inspected default-branch tree did not expose an executable SECA service, verifier adapter implementation or test suite. Its node descriptor says `lifecycle: active-candidate` and `runtime_state: unverified`. Treat SECA as specified, not live-certified.
2. **End-to-end event circulation is explicitly PARTIAL.** The Event Gateway recursive integration document states that the organism remains PARTIAL until a real mission is reconstructed through participating organs with receipts.
3. **CrownGrid is more mature at source level, not yet operationally certified here.** A capability/locality/load router, execution envelope and test source exist. This audit did not execute those tests or call a live routing endpoint.
4. **The physical sensory loop has a durability gap.** Map of Reality documents an ephemeral process cache and says durable Thoth/SESHAT writeback is a later promotion gate. A live public map response is not a substitute for durable evidence.
5. **The documented physical ingest path is GitHub Actions OIDC-dependent.** The user's standing no-Actions constraint prohibits using, creating, modifying, enabling or rerunning Actions as the verification path. Do not trigger that workflow. Replace this dependency only through an already-authorized non-Actions physical runtime/ingest contract; until then, mark physical census freshness UNVERIFIED/STALE.
6. **Registry and mesh source contracts remain unresolved.** Service Catalog and Estate Service Mesh are referenced as canonical authorities by CrownGrid but were not inspected. Do not invent endpoints or duplicate either service.
7. **Cross-organ return is not proven.** A Thoth ingestion implementation and tests exist, but this pass did not verify a live SECA → ProofGrid → Thoth → SESHAT/Universal Atlas → RETURN transaction.
8. **No current live organism-health verdict was generated.** A repository audit cannot establish that services are running, dependencies are reachable, physical hardware is healthy or event subscribers are consuming messages.
